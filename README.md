# Vibe Coding Starter Kit

AIにコードを書いてもらう時に使う「設定ファイルのセット」です。

## これは何？

AIと一緒に開発する時、毎回こんなことしてませんか？

- 「ファイル構成はこうで、ルールはこうで…」とイチから説明してる
- AIが勝手に暴走して、頼んでないことまでやってしまう
- 途中で進捗がわからなくなる

**このキットを入れておくと、AIが最初からルールを理解した状態で動きます。**

---

## 用語の説明

このREADMEで出てくる言葉を先に説明します。

| 言葉 | 意味 | 例 |
|------|------|-----|
| エディタ | コードを書くためのアプリ | Cursor, Antigravity, Windsurf |
| AIモデル | AIの頭脳。エディタの中で動く | Claude, Gemini, GPT |
| ターミナル | 文字だけで操作する黒い画面 | Mac の「ターミナル」アプリ |
| スキル | AIへの指示書。やり方が書いてある | `/plan`, `/review` 等 |
| セットアップ | 最初の準備。1回やればOK | `bash setup.sh ...` |

> **エディタとモデルは別物です。**
> エディタ = 道具、モデル = AIの頭脳。
> 1つのエディタで色んなモデルが使えます。
> 例: Antigravity（エディタ）で Claude（モデル）を使う、など。

## 始め方（3ステップ）

### ステップ 1: ターミナルでセットアップを実行する

ターミナルを開いて、以下を打ちます:

```bash
cd Desktop/starter-kit
bash setup.sh my-app
```

> **`my-app` の部分は好きな名前に変えてOKです。**
> 例: `bash setup.sh reservation-app`（予約アプリ）
> 例: `bash setup.sh snkr-hub-checker`（SNKRのチェッカー）

画面にこんな選択肢が出ます。自分が使うエディタの番号を打ってください:

```
  1) Claude Code
  2) Cursor
  3) Windsurf
  4) Antigravity
  5) Gemini CLI
  6) Codex

番号を入力 (例: 1 or 1 2):
```

> 番号を打たずに、名前で直接指定もできます:
> ```bash
> bash setup.sh my-app antigravity
> ```

これで `my-app` というフォルダが作られます。
中にAIが読むルールやスキルが入っています。

### ステップ 2: エディタでそのフォルダを開く

ステップ1で作られたフォルダを、自分のエディタで開きます。
**既にエディタを開いていた場合は、一度再起動してください。**（新しいファイルが読み込まれません）

| エディタ | 開き方 |
|---------|--------|
| Antigravity | Antigravity を起動 → 作られたフォルダを開く |
| Cursor | Cursor を起動 → File → Open Folder → 作られたフォルダを選ぶ |
| Windsurf | Windsurf を起動 → File → Open Folder → 作られたフォルダを選ぶ |
| Claude Code | ターミナルで `cd my-app` と打つ → `claude` と打つ |
| Gemini CLI | ターミナルで `cd my-app` と打つ → `gemini` と打つ |
| Codex | ターミナルで `cd my-app` と打つ → `codex` と打つ |

### ステップ 3: AIに話しかける

エディタのチャット欄に、こう打ちます:

```
このプロジェクトを初期化して
```

AIが「何を作りますか？」と聞いてくるので、会話しながら進めます。
AIはキットのルールを読んで動くので、勝手に暴走しません。

## セットアップ後の流れ

```
「このプロジェクトを初期化して」
      ↓
AIが「何を作る？」「技術スタックは？」と聞いてくる
      ↓
答えると、設計書やタスク一覧が自動で作られる
      ↓
「始めて」と言うと、タスクを1個ずつ進めてくれる
      ↓
各ステップで「これでいい？」と確認してくる
      ↓
OKと言えば次に進む。ダメなら修正してくれる
```

**大事なポイント: AIは勝手に全部やりません。必ず確認を挟みます。**

## 開発中にできること

AIにこう言うだけで使えます。コマンドを覚える必要はありません。

| こう言えば | AIがやってくれること |
|-----------|-------------------|
| 「進捗見せて」 | いま何%終わったか見せてくれる |
| 「バックアップして」 | GitHubに保存してくれる |
| 「コミットして」 | 変更内容を見てコミットしてくれる |
| 「コードレビューして」 | 問題点を見つけてくれる |
| 「この機能を計画して」 | タスクに分けて計画してくれる（まだコードは書かない） |
| 「このバグ直して」 | 原因を見つけて直してくれる |
| 「テスト作って」 | テストを自動で作ってくれる |
| 「セキュリティチェックして」 | 危ない部分がないか調べてくれる |

## よくある質問

### Q: エディタの中でAIモデルを切り替えたら、setup.shをやり直す必要がある？

**ありません。** AIモデル（Claude, Gemini等）を切り替えても、エディタが読む設定ファイルは同じです。

### Q: 複数のエディタを使いたい場合は？

セットアップ時に複数選べます:

```bash
bash setup.sh my-app antigravity claude-code
```

### Q: GitHubのバックアップ機能を使うには？

GitHubのアカウントと認証設定が事前に必要です。これはキットの範囲外で、各自で設定してください。
