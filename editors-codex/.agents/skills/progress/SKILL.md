# 進捗ダッシュボード

`docs/tasks.md` を読み込んで進捗を表示する。

手順:
1. docs/tasks.md の全チェックボックスをカウント
2. `[x]` = 完了、`[ ]` = 未完了
3. Phase別の完了率を計算
4. 以下のフォーマットで表示:

```
==============================
  {{PROJECT_NAME}} 進捗状況
==============================
  Phase 1: ████████░░ 80% (4/5)
  Phase 2: ███░░░░░░░ 30% (3/10)
  Phase 3: ░░░░░░░░░░  0% (0/4)
------------------------------
  全体:    ████░░░░░░ 37% (7/19)
------------------------------
  次のタスク: 2.4 検索機能の実装
==============================
```

5. docs/tasks.md の「進捗サマリー」セクションも最新の数値に更新
