# 不要コード検出

使われていないコード、import、変数を見つけて削除する。

## 手順

### ステップ1: 言語別の自動検出ツールを確認

| 言語 | ツール/設定 | 検出方法 |
|------|-----------|---------|
| TypeScript | `tsc --noUnusedLocals --noUnusedParameters` | コンパイラで検出 |
| TypeScript | `eslint` の `no-unused-vars` | Lintで検出 |
| Python | `vulture` / `pylint` | 静的解析で検出 |
| Go | コンパイラが自動検出 | ビルド時にエラー |

ツールがあれば実行を提案する。なければ手動検索に進む。

### ステップ2: 手動検索

以下のパターンをプロジェクト全体で検索する:

1. **未使用import**: import文で取り込んだがファイル内で使っていないモジュール
2. **未使用関数**: 定義されているが、プロジェクト内のどこからも呼ばれていない関数
3. **未使用変数**: 宣言されているが参照されていない変数
4. **到達不能コード**: return/throw 後のコード
5. **コメントアウトされたコード**: 大きなコードブロックがコメントアウトされている

検索方法:
- 関数定義を検出 → その関数名でプロジェクト全体をgrep → 定義箇所以外に参照がなければ不要

### ステップ3: 信頼度の評価

| 信頼度 | 条件 | アクション |
|--------|------|-----------|
| HIGH | 参照が0件。exportもされていない | 安全に削除可能 |
| MEDIUM | テストからのみ参照されている | テストと一緒に削除を検討 |
| LOW | 動的importやリフレクションの可能性 | ユーザーに確認が必要 |

### ステップ4: 結果を出力

```
## 不要コード検出結果

| # | ファイル | 行 | 種類 | 名前 | 信頼度 | 理由 |
|---|---------|-----|------|------|--------|------|
| 1 | src/utils/old.ts | 1-50 | ファイル全体 | old.ts | HIGH | import が0件 |
| 2 | src/api/users.ts | 15 | 関数 | formatLegacy() | HIGH | 参照0件 |
| 3 | src/hooks/useAuth.ts | 3 | import | lodash | HIGH | 未使用 |
| 4 | src/lib/cache.ts | 42 | 関数 | invalidate() | LOW | 動的呼び出しの可能性 |

### サマリー
- HIGH (安全に削除可能): X件
- MEDIUM (確認推奨): X件
- LOW (要確認): X件
- 削除で減らせるコード: 約XX行
```

### ステップ5: 削除の実行

1. ユーザーに確認してからHIGHのものだけ削除する
2. MEDIUM/LOWはユーザーの判断を仰ぐ
3. 削除後にテストを実行して問題がないことを確認する

## 安全ルール

**以下は削除しない:**
- `export` されている関数/変数（外部から使われている可能性）
- バレルファイル（index.ts）での re-export
- 動的import（`import()` や `require()`）で参照される可能性のあるもの
- package.json の `bin` や `main` で指定されているファイル

## エッジケース

| 状況 | 対処 |
|------|------|
| テストがない | 「テストなしでの削除はリスクがあります」と警告 |
| モノレポ | パッケージ境界をまたぐ参照も確認する |
| 設定ファイルからの参照 | webpack.config, next.config 等も検索対象に含める |
