# タスクボード

チェックボックス付きのタスク一覧を作って、作業が終わるたびにリアルタイムで更新する。

## タスクファイルを新規作成する時

1. ユーザーにやりたいことを聞く
2. タスクを分解してチェックボックス形式で TASKS.md を作成:
   ```
   # プロジェクト名 タスク
   ## 進捗サマリー
   - Phase 1: 0/N 完了
   - 全体: 0/N 完了 (0%)

   ## Phase 1: ...
   - [ ] タスク1
   - [ ] タスク2
   ```
3. 各タスクは「15分以内で終わる」「完了条件が明確」な粒度にする

## 作業中のリアルタイム更新

1. タスクを1つ完了するたびに:
   - `[ ]` を `[x]` に更新
   - 進捗サマリーの数字を更新
   - 完了ログにタスク名と日時を追記
2. 次のタスクに自動で進む
3. Phase が全部終わったら次の Phase に進む

## 既存の TASKS.md がある場合

1. TASKS.md を読んで現在の進捗を把握
2. `/progress` と同じダッシュボードを表示
3. 次のタスクを提示して作業を続ける
