# AI文章の自然化
AI臭い文章を自然な日本語に書き直す。
検出パターン:
- 「なお」「また」の多用
- 「～いたします」「～させていただきます」の過剰な丁寧語
- 「包括的に」「網羅的に」等の抽象的な修飾語
- 箇条書きの羅列で文章のつながりがない
- 同じ構文の繰り返し
修正方針:
- 話し言葉に近い自然な表現
- 具体的な言葉に置き換え
- 不要な修飾語を削除
- 短い文で歯切れよく
