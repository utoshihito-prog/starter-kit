## サービス用語

| 用語 | 定義 | 主な登場フロー |
|---|---|---|
| 故障対応 | 利用端末に故障が発生した際、交換品を手配し、キッティング後に顧客へ発送する対応 | 故障対応、月次レポート |
| 盗難紛失時の端末再貸与 | 端末の盗難・紛失発生時に、遺失届等を確認したうえで交換品を再貸与する対応 | 盗難紛失時の端末再貸与、月次レポート |
| リクエストキッティング | 利用者変更や誤初期化などにより、既存端末をKへ送付して再キッティングする対応 | リクエストキッティング、月次レポート |
| キッティング / KIT | 端末を業務利用できる状態にする設定作業。MDMプロファイル投入、アプリ設定、ポリシー適用、動作確認を含む | 故障対応、盗難紛失時の端末再貸与、リクエストキッティング |
| キッティング手順書 / KIT手順書 | 企業・機種・パターン別のキッティング作業手順をまとめた資料 | 3フロー共通 |
| 故障交換機器送付依頼書 | 故障時に交換品送付を依頼するExcel様式 | 故障対応 |
| 紛失時対応依頼書 | 盗難・紛失時に交換品送付と再貸与を依頼するExcel様式 | 盗難紛失時の端末再貸与 |
| 端末キッティング依頼書 | リクエストキッティングを依頼するExcel様式 | リクエストキッティング |
| 受付管理簿 | 依頼受付、発送、完了、端末情報を管理する台帳。代理店によってExcel、kintone、Power Appsなどの実装差がある | 3フロー共通、月次レポート |
| 承り連絡 | Kが企業管理者へ正式受付を知らせるメール。原則、依頼元メールへ全返信する | 3フロー共通 |
| 不備確認 | 依頼書の記入漏れ、契約名義、機種、送付先、ABM/ASM組織IDなどを確認する作業 | 3フロー共通 |
| 操作代行 | 本来は企業管理者が行うMDM/ABM操作を、Kが代わりに実施するサービス | 3フロー共通 |
| 月次レポート | 当月のキッティング、ヘルプデスク、盗難紛失サポート等の対応実績をまとめた報告書 | 月次レポート |
| お客様情報シート | 企業管理者、報告書送付先、所在地、連絡先、メールアドレスを管理するシート | 月次レポート |
| ファイル転送サービス | 月次レポート等を送付するためのWebサービス。企業ごとに利用サービスが異なる | 月次レポート |

## 技術用語

| 用語 | 定義 | 注意点 |
|---|---|---|
| MDM | Mobile Device Management。端末の設定配布、アプリ管理、リモートロック、リモートワイプ等を行う端末管理システム | 不要端末のデバイス削除を怠るとゴミデータやライセンス費用増につながる |
| ABM | Apple Business Manager。法人向けのApple端末・アカウント・アプリ管理基盤 | 依頼書では組織IDがキッティング時の割当キーになる |
| ASM | Apple School Manager。教育機関向けのApple管理基盤 | ABMと同等の用途で扱うが教育機関向け |
| ADE | Automated Device Enrollment。旧DEP。Apple端末をMDMへ自動登録する仕組み | 依頼書ではABM/ASM（DEP）と記載されることがある |
| SIMカード / UIMカード | 物理的なICカード型SIM。電話番号や契約情報を保持する | 故障時は旧端末から新端末へ差し替える。盗難紛失時は再発行対象になる |
| eSIM | 端末内蔵型の電子SIM | プロファイルダウンロードにより開通する。フローによりK実施または利用者実施が分かれる |
| プロファイルダウンロード | eSIMの通信設定を端末へダウンロードして開通する操作 | 故障時は利用者側で実施する場合があり、リクエストキッティングではKが作業時に実施する場合がある |
| デバイス削除 | MDMから不要端末の管理情報を削除する操作 | 故障、盗難紛失、再キッティングで必要になる |
| 所有状態解除 | ABM/ASM上で端末を企業の所有状態から外す操作 | 回収端末を他企業へ転用可能にする目的で実施する |
| リモートロック | 紛失・盗難時にMDM等で端末を遠隔ロックする操作 | 24時間365日サポートの対象になる場合がある |
| リモートワイプ | 紛失・盗難時に端末データを遠隔消去する操作 | 実行後の復元可否や顧客承認が重要 |

## 補償・賠償関連

| 用語 | 定義 | 金額・条件 |
|---|---|---|
| レンタルあんしん補償オプション | 故障・紛失時の顧客負担を軽減する補償オプション | 故障時は未返却時賠償金を除き無料。紛失時は加入時無料の記載あり |
| 未返却時賠償金 | 故障機が期限内に返却されない、または初期化されず返却された場合の賠償金 | 交換機器受領後2週間以内の返却が必要。補償オプション対象外 |
| 紛失時賠償金 | 盗難・紛失時に条件を満たさない、または補償未加入の場合に発生する賠償金 | 初期契約期間は割引前レンタル料総額、再レンタル期間は1回目3,000円、2回目以降は割引前レンタル料総額 |
| UIMカード・eSIM再発行手数料 | SIM/eSIM再発行時の手数料 | 2025年9月5日以降は4,950円（税込）。改定前は3,850円（税込） |
| 遺失届受理番号 | 警察へ盗難・紛失を届け出た際の受理番号 | オンライン申請時は警察署名不要。社内紛失等で取得できない場合は会社印押印の経緯書が必要 |
