# 月次レポート対応フロー

## 概要

本フローは、K（代理店/ヘルプデスク）が当月中のヘルプデスク等の対応実績を集計し、月次レポートとして報告するまでの一連の流れを定義したものです。
K（ヘルプデスク）での対応件数集計・月次レポート作成から、N（携帯会社/協力会社管理部門）による自社フォーマットへの落とし込みを経て、企業管理者への報告書送付・ダウンロードまでの手順を網羅しています。

なお、本フローはN（携帯会社）が受託した案件をK（代理店）へ再委託した体制を想定しています。そのため、当月の実績を成果物として企業管理者へ報告する役割はN（携帯会社）が担います。

---

## 登場人物（スイムレーン）

| レーン | 説明 |
|--------|------|
| **企業管理者** | 法人契約の管理担当者。月次レポートの最終的な受領者。ファイル転送サービスから報告書をダウンロードして確認する |
| **N（携帯会社） 協力会社管理部門** | 携帯会社側の窓口。K（ヘルプデスク）から月次レポートを受領し、自社フォーマットに落とし込んだうえで企業管理者へ報告する |
| **K（代理店） ヘルプデスク** | 携帯会社（N）から再委託を受けている代理店。対応件数の集計および月次レポートの作成を担当する |

## フロー詳細

### Phase 1：対応件数集計・月次レポート作成〜送付

#### このPhaseで登場する用語

| 用語 | 説明 |
|------|------|
| **月次レポート** | 当月中のヘルプデスク等の対応実績（対応件数など）をとりまとめた報告書 |
| **故障対応** | 利用者の端末が故障した際に、代替端末への交換（故障交換）を行う対応。故障した端末をK（ヘルプデスク）へ送付し、キッティング済みの交換端末を返送する流れが一般的。キッティングの対応件数としてカウントされる |
| **盗難紛失時の端末再貸与** | 利用者が端末を盗難・紛失した際に、新たな端末をキッティングして貸与する対応。SIMカードの再発行手続きといった付随作業が発生する場合がある。キッティングの対応件数としてカウントされる |
| **リクエストキッティング（利用者変更／再キッティング）** | 端末の利用者が変更になった場合や、誤って端末を初期化してしまった場合などに、再度キッティング（業務利用のためのセットアップ）を行う対応。故障交換とは異なり端末自体の交換は発生しない。キッティングの対応件数としてカウントされる |
| **ヘルプデスク対応** | 端末の操作方法や設定に関する問い合わせに対応する業務。業務委託契約に含まれる場合、問い合わせ件数を月次レポートに明記し、折衝記録（いつ、どのような問い合わせがあり、どう回答したか）を別紙で添付する。キッティングの対応件数とは別に、契約期間内や当月の対応件数の上限が定められている場合がある |
| **盗難紛失時のサポート対応（24時間365日受付）** | 端末の盗難・紛失が発生した際に、時間帯を問わず受付対応を行う業務。MDMによるリモートロック・リモートワイプの即時実施や、回線の一時停止手配などを含む。体制構築費用として余剰の工数が含まれていることもあるため、契約期間内や当月の対応件数の上限が定められていない場合がある |
| **「お客様情報」シート** | 企業管理者ごとの連絡先・報告書送付先を一覧で管理するシート。管理項目はNo、担当業務、部署名、氏名、所在地、連絡先（TEL / MB）、メールアドレス、備考。各企業管理者に対して「報告書送付先」（部署名・所在地）が紐づいて管理されている。企業管理者など情報変更が生じた際は、営業担当者に速やかに情報提供を行う必要がある |
| **ファイル転送サービス** | 報告書を送付するために利用するWebベースのファイル送受信サービス。利用しているサービスは企業によって異なる（Ften／BOX 等）。アクセス不可やファイルの閲覧不可などが発生した場合は協力会社管理部門へ連絡する |

#### フロー

1. **【K（ヘルプデスク）】対応件数集計 / 月次レポート作成** 📄
   - 当月中のヘルプデスク等の対応実績をとりまとめる
   - 月次レポートの報告内容はN（携帯会社）との業務委託契約の内容によって異なる
   - キッティング業務については対応件数に上限（契約期間内に100件の対応まで等）を設けており、上限を超えないか確認するために、当月における以下の件数を月次レポートに記載する
     - 故障対応
     - 盗難紛失時の端末再貸与
     - リクエストキッティング（利用者変更／再キッティング）

> **補足①：** 業務委託契約にヘルプデスク対応が含まれる場合は、問い合わせ件数を月次レポートに明記する。加えて、ヘルプデスクの折衝記録（いつ、どのような内容の問い合わせがあり、どう回答したか）も別紙として添付する。なお、ヘルプデスク対応はキッティングの対応件数とは別に、契約期間内や当月の対応件数の上限が定められている場合がある。
>
> **補足②：** 業務委託契約に24時間365日受付可能な盗難紛失時のサポート対応が含まれる場合も同様に、月次レポートに明記する。なお、この業務は体制構築費用として余剰の工数が含まれていることもあるため、契約期間内や当月の対応件数の上限が定められていない場合がある。

2. **【K（ヘルプデスク）→N（協力会社管理部門）】月次レポート送付** 📧📄
   - 作成した月次レポートをN（協力会社管理部門）へ送付する
   - 「**お客様情報**」シートに記載の報告書送付先へ送付する
   - ファイル転送サービスを利用して報告書を送付する。利用しているサービスは企業によって異なる（Ften／BOX 等）

3. **【N（協力会社管理部門）】受領**
   - K（ヘルプデスク）から送付された月次レポートを受領する

---

### Phase 2：自社フォーマットへの落とし込み〜企業管理者への報告

#### フロー

4. **【N（協力会社管理部門）】自社フォーマットへの落とし込み** 📄
   - K（ヘルプデスク）から受領した月次レポートの内容を、N（協力会社管理部門）の自社フォーマットに落とし込む

5. **【N（協力会社管理部門）→企業管理者】月次レポート送付** 📧📄
   - N（協力会社管理部門）から企業管理者へ月次レポートを送付する
   - ファイル転送サービスを利用して報告書を送付する
   - ファイル転送サービスへのアクセス不可やファイルの閲覧不可などが発生した場合は、協力会社管理部門へ連絡する

6. **【企業管理者】月次レポートのダウンロード** 🌐
   - ファイル転送サービスから月次レポートをダウンロードする
