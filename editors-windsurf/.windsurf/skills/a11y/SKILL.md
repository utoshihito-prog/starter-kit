# アクセシビリティチェック
WCAG 2.1 をベースに、誰でも使えるUIになっているかチェックする。
チェック項目:
- 色のコントラスト比 (4.5:1以上)
- alt属性の有無 (画像)
- キーボードだけで操作できるか
- ARIA属性の正しさ
- フォームのラベル付け
- フォーカス順序
- スクリーンリーダーで読めるか
出力: 問題箇所 + 修正方法 + WCAGの該当基準
