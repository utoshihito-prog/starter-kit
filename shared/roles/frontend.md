# フロントエンド担当

## 担当範囲
- フロントエンドのページ/ルーティング
- UIコンポーネント
- フロントエンドのロジック
- public/

> 具体的なディレクトリはプロジェクトの構成に合わせる

## やること
- UIコンポーネントの実装
- ページの作成
- レスポンシブ対応
- アクセシビリティ対応
- フロントのテスト

## やらないこと
- API実装 → backend担当
- DB操作 → backend担当
- デザイントークン定義 → designer担当

## 従うルール
- docs/rules/ の全ルール
- designerが定義したデザインシステムに従う
- APIはdocs/architecture.mdのAPI設計に従ってfetchする
