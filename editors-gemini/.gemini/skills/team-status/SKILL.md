# チーム進捗確認

roles/ と tasks.md を読んで、役割別の進捗を報告する。

## 手順

1. roles/ の全ファイルを読んで役割一覧を取得
2. tasks.md の各タスクの担当タグ [frontend] [backend] 等を解析
3. 役割別の進捗を計算して表示:

```
==============================
  チーム進捗状況
==============================
  architect:  ██████████ 100% (2/2)  全体設計完了
  frontend:   ████░░░░░░  40% (2/5)  トップページ作業中
  backend:    ██████░░░░  60% (3/5)  API認証完了
  designer:   ██████████ 100% (3/3)  デザイン完了
------------------------------
  全体:       ██████░░░░  67% (10/15)
------------------------------
  ブロック: なし
  次の優先: フロント - お問い合わせページ
==============================
```

4. ブロック(他の担当待ちで進めないタスク)があれば警告
5. tasks.md の進捗サマリーを更新
