# 進捗ダッシュボード

> **このスキルの役割**: 現在の進捗を素早く確認する（読み取り専用）。
> タスクの作成・更新は /taskboard で行う。チーム別の進捗は /team-status を使う。

`docs/tasks.md` を読み込んで進捗を表示する。

## 手順

### ステップ1: tasks.md を読み込む
1. docs/tasks.md が存在するか確認する
2. 存在しない場合: 「docs/tasks.md がありません。/taskboard でタスクを作成してください」と案内して終了
3. 全チェックボックスをカウントする: `[x]` = 完了、`[ ]` = 未完了

### ステップ2: 進捗を計算して表示

```
==============================
  {{PROJECT_NAME}} 進捗状況
==============================
  Phase 1: ████████░░ 80% (4/5)
  Phase 2: ███░░░░░░░ 30% (3/10)
  Phase 3: ░░░░░░░░░░  0% (0/4)
------------------------------
  全体:    ████░░░░░░ 37% (7/19)
------------------------------
  次のタスク: 2.4 検索機能の実装
==============================
```

### ステップ3: tasks.md の進捗サマリーを更新
- 「進捗サマリー」セクションがあれば最新の数値に更新する
- なければ先頭に追加する

## エッジケース

| 状況 | 対処 |
|------|------|
| tasks.md がない | /taskboard を案内 |
| Phase分けがない | 全タスクを1つのグループとして表示 |
| 全タスク完了 | 「全タスク完了！お疲れさまでした」と表示 |
| チェックボックスがない | 「タスクがチェックボックス形式ではありません」と警告 |
