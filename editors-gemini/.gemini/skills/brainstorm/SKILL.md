# ブレインストーミング

コードを書く前に「本当にそれでいい？」を深掘りする対話。

進め方:
1. $ARGUMENTS のテーマを受け取る
2. 以下の質問で深掘り:
   - そもそも何を解決したい？
   - ユーザーは誰？どう使う？
   - 似た機能は既にある？
   - 一番シンプルな実現方法は？
   - エッジケースは？
   - スケールした時に問題は？
3. 2〜3の設計案を提示して比較
4. ユーザーが選んだ案を /plan に渡せる形でまとめる
