# ダミーデータ生成

開発・テスト用の本物っぽいデータを大量に作る。

手順:
1. データモデルを docs/architecture.md やスキーマファイルから把握
2. 各エンティティに対してリアルなデータを生成:
   - 名前: 実際にありそうな日本語の名前
   - メール: example.com ドメイン
   - 日付: 直近1年以内のランダムな日付
   - リレーション: 外部キーの整合性を保つ
3. シードスクリプト or JSON ファイルとして出力
4. データ量はユーザーに確認 (デフォルト: 各エンティティ20件)
