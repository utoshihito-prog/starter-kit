# 不要コード検出

使われていないコード、import、変数を見つけて削除する。

手順:
1. プロジェクト全体をスキャン
2. 以下を検出:
   - import されているが使われていないモジュール
   - 定義されているが呼ばれていない関数
   - 宣言されているが参照されていない変数
   - 到達不能なコード (return 後のコード等)
   - コメントアウトされたコードブロック
3. 検出結果をリストで報告
4. ユーザーに確認してから削除
5. テストが通ることを確認
