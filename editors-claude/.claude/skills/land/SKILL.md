# セッション締めくくり（Land the Plane）

1タスク完了時の全自動クリーンアップ。

## 手順

### 1. フォローアップの記録
- 作業中に気づいた TODO やフォローアップがあれば docs/tasks.md に追記

### 2. 品質ゲート
以下を順番に実行。失敗したら自動で修正して再実行:

a) scripts/verify.sh があれば実行
b) なければ以下を個別実行:
   - テスト (検出したテストコマンド)
   - リント (検出したリントコマンド)
   - フォーマット (検出したフォーマットコマンド)
   - 型チェック (検出した型チェックコマンド)

### 3. コミット
- git add で変更ファイルをステージ（ファイル名を明示）
- 変更内容から日本語コミットメッセージを生成
- 形式: `<種別>: <内容>`
- .env やシークレットが含まれていないか確認
- git commit

### 4. プッシュ
- git push origin
- リモートが未設定なら「リモートがありません。/backup で設定しますか？」と提案

### 5. タスク更新
- docs/tasks.md の該当タスクを [x] に更新
- 進捗サマリーの数字を更新

### 6. 完了報告と次のタスク提案

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ✓ タスク完了: [タスク名]
  コミット: abc1234
  テスト: 全通過 (15/15)
  リント: OK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  進捗: ██████░░░░ 60% (9/15)
  次のタスク: [次のタスク名]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

「続けますか？コンテキストが大きくなっている場合、新しいセッションで始めることをおすすめします」

## 失敗時の対処

| ステップ | 失敗 | 対処 |
|---------|------|------|
| 品質ゲート | テスト失敗 | エラーを表示し自動修正を試みる。3回失敗したら停止して報告 |
| 品質ゲート | リント失敗 | `lint:fix` を自動実行。修正後に再ステージ |
| 品質ゲート | テストコマンドがない | 「テストコマンドが見つかりません」と警告してスキップ |
| コミット | pre-commit フック失敗 | エラー内容を確認して自動修正。修正後に新しいコミットを作る |
| プッシュ | 認証エラー | 「`gh auth login` を実行してください」と案内 |
| プッシュ | リモートなし | /backup を提案 |
| プッシュ | コンフリクト | `git pull --rebase` を提案 |
| タスク更新 | tasks.md がない | 警告のみ。コミット・プッシュは完了させる |
