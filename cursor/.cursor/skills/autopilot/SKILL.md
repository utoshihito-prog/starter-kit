# 一気通貫モード (Autopilot)

計画を承認したら、あとは全タスクが完了するまで自動で走り続ける。
開発 → レビュー → 修正 → テスト → コミット → 次のタスク を自動で繰り返す。

## 注意: このモードを使う前に

このモードは**人間のチェックなしで複数のタスクを連続実行する**。
便利だが、間違った方向に全力で走るリスクもある。

起動時に必ず以下を確認する:

```
===================================================
  一気通貫モード (Autopilot) を起動します

  以下を確認してください:
  1. plans/ に承認済みの計画がありますか？
  2. テストが通る状態ですか？
  3. git の状態はクリーンですか？

  このモードでは人間の確認なしで
  開発→レビュー→修正→テストを繰り返します。

  本当に起動しますか？ [yes/no]
===================================================
```

「yes」以外の回答では起動しない。

## 動作フロー

```
plans/ から承認済み計画を読む
    │
    ▼
┌─────────────────────────────────┐
│ タスクを1つ取り出す              │◄────────────┐
│ (docs/tasks.md の次の未完了)      │              │
└──────────┬──────────────────────┘              │
           │                                    │
           ▼                                    │
┌─────────────────────────────────┐              │
│ 実装する                         │              │
│ (小さい差分で)                    │              │
└──────────┬──────────────────────┘              │
           │                                    │
           ▼                                    │
┌─────────────────────────────────┐              │
│ セルフレビュー                    │              │
│ (context:fork で隔離チェック)     │              │
│ - バグ・型エラー                  │              │
│ - セキュリティ                    │              │
│ - エッジケース                    │              │
└──────────┬──────────────────────┘              │
           │                                    │
           ├── 問題あり → 修正 → 再レビュー ─┐    │
           │                                │    │
           ▼                                │    │
┌─────────────────────────────────┐          │    │
│ テスト・リント・型チェック         │◄─────────┘    │
│ (scripts/verify.sh)             │              │
└──────────┬──────────────────────┘              │
           │                                    │
           ├── 失敗 → 修正 → 再テスト ──────────┤
           │                                    │
           ▼                                    │
┌─────────────────────────────────┐              │
│ コミット + tasks.md 更新         │              │
│ (1タスク = 1コミット)            │              │
└──────────┬──────────────────────┘              │
           │                                    │
           ├── 次の未完了タスクがある → ─────────┘
           │
           ▼
┌─────────────────────────────────┐
│ 全タスク完了                      │
│ - git push                       │
│ - 進捗ダッシュボード表示           │
│ - 完了報告                        │
└─────────────────────────────────┘
```

## 安全装置

### 自動停止する条件
- 同じエラーが3回連続で直せない → 「ここで行き詰まりました。人間の判断が必要です」と報告して停止
- コンテキスト使用率が40%を超えた → 現在のタスクを完了させてからセッションを中断。「/autopilot で再開してください」と案内
- 安全境界に該当する変更が必要になった (認証・課金・DB migration 等) → 「この変更は人間の確認が必要です」と停止

### 各タスク完了時のログ
タスクごとに以下を記録:
```
[タスク名] 完了
- 変更ファイル: src/xxx.ts, src/yyy.ts
- テスト結果: 全通過
- レビュー結果: 問題なし
- コミット: abc1234
```

### 途中で止めたい場合
- Ctrl+C で即座に停止
- 最後にコミットされた時点まではクリーンな状態
