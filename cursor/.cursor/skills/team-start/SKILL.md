# チーム開発モード

人間は管理者(自分)とだけやり取り。自分が各役割を順番に切り替えて実行する。

## 手順

### 1. プロジェクトの種類を聞く
- HP制作 → architect + frontend + designer
- SaaS開発 → architect + frontend + backend + designer
- API開発 → architect + backend
- その他 → ユーザーに役割を聞く

### 2. roles/ に役割定義を生成
各役割ファイルに以下を定義:
- 担当ディレクトリ (このフォルダだけ触る)
- やること
- やらないこと (他の担当に任せる)
- 従うルール

### 3. tasks.md のタスクに担当者を振り分け
```
- [ ] トップページ実装 [frontend]
- [ ] API認証エンドポイント [backend]
- [ ] デザイントークン定義 [designer]
```

### 4. 各役割を順番に実行
管理者が自分で順番に各役割を切り替えて実行する:
1. roles/architect.md を読んで設計タスクを実行
2. roles/frontend.md を読んでフロントのタスクを実行
3. roles/backend.md を読んでバックのタスクを実行
4. 各タスク完了後にtasks.mdのチェックボックスを更新

### 5. 結果をまとめる
- 各役割の成果をレビュー
- 衝突があれば解決
- 進捗をユーザーに報告

## 並列エージェントの注意

- 並列エージェントの上限: 1人のレビュアーで統合する場合、3-4エージェントが現実的な上限
- サブエージェントには必ず目的文を含める（NG:「認証を調べて」 OK:「レート制限改善のために認証を調べて」）
