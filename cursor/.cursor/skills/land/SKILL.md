# セッション締めくくり（Land the Plane）

1タスク完了時の全自動クリーンアップ。

## 手順

### 1. フォローアップの記録
- 作業中に気づいた TODO やフォローアップがあれば docs/tasks.md に追記

### 2. 品質ゲート
以下を順番に実行。失敗したら自動で修正して再実行:

a) scripts/verify.sh があれば実行
b) なければ以下を個別実行:
   - テスト (検出したテストコマンド)
   - リント (検出したリントコマンド)
   - フォーマット (検出したフォーマットコマンド)
   - 型チェック (検出した型チェックコマンド)

### 3. コミット
- git add で変更ファイルをステージ
- 変更内容から日本語コミットメッセージを生成
- 形式: <種別>: <内容>
- .env やシークレットが含まれていないか確認
- git commit

### 4. プッシュ
- git push origin
- リモートが未設定なら「リモートがありません。/backup で設定しますか？」と提案

### 5. タスク更新
- docs/tasks.md の該当タスクを [x] に更新
- 進捗サマリーの数字を更新

### 6. 次のタスク提案
- docs/tasks.md の次の未完了タスクを提示
- 「続けますか？新しいセッションで始めることをおすすめします」と提案
