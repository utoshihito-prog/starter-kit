# パターン自動学習
「毎回やってる作業」を見つけてスキルにする。
手順:
1. 直近のセッション履歴を分析
2. 2回以上繰り返されたパターンを検出:
   - 同じ順序で実行されたコマンド
   - 同じ種類のファイルに対する同じ操作
   - 定型的な質問→回答の流れ
3. パターンを提案: 「これをスキルにしますか？」
   - スキル名の候補
   - 何をするスキルか
   - 手順の要約
4. ユーザーが承認したら /save-skill と同じ流れでスキル化

セッション終了前に手動で `/self-learn` を実行してください。
