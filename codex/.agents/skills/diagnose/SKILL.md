# バグ診断

バグの原因を体系的に見つけて、修正案と回帰テストを提案する。

手順:
1. $ARGUMENTS の症状を確認
2. 再現手順を特定:
   - どういう操作で起きるか
   - エラーメッセージの確認
3. `git log --oneline -10` で最近の変更を確認
4. 関連コードを読んでデータの流れを追う
5. 原因を特定:
   - 仮説を立てる
   - コードで裏付ける
6. 修正案を提示:
   - 最小限の修正
   - Before/After
7. 回帰テストを提案
