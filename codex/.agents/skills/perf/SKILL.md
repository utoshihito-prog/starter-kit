# パフォーマンス分析
コードの遅い部分を見つけて、速くする方法を提案する。
チェック項目:
- O(n^2)以上のアルゴリズム
- N+1クエリ問題
- 不要な再レンダリング・再計算
- キャッシュできるのにしていない箇所
- 大きすぎるバンドルインポート
- インデックスが貼られていないDBクエリ
- メモリリーク (閉じていないリソース)
出力: 問題箇所 + 修正案 + 期待される改善度
